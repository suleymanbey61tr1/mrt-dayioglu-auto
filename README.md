## 🚀 Kurulum

Projeyi bilgisayarınıza indirin.

```bash
git clone https://github.com/KULLANICI_ADIN/mrt-dayioglu-auto.git
```

Proje klasörüne girin.

```bash
cd mrt-dayioglu-auto
```

Bağımlılıkları yükleyin.

```bash
npm install
```

Projeyi başlatın.

```bash
npm run dev
```

Production build oluşturun.

```bash
npm run build
```
